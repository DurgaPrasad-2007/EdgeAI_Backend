📊 Contract-Net Protocol (CNP)
Decentralized task auctions. AMRs compute scalar utility U = 0.4P - 0.35D + 0.25(B - 20%). Highest bidder claims task in <15ms without central server.

Mutex lock for single-lane corridors (e.g. Corridor C-14). 4.8s TTL with auto-expiry. Deterministic ID tie-breaking prevents deadlocks and livelocks.

Key Architectural Highlights (Defense & Industrial Standards)

Decentralized Swarm Intelligence

Each robot calculates its own allocation and paths. Complete immunity against central cloud or Wi-Fi blackout.

Contract-Net Protocol (CNP)

Mathematical utility bidding factoring priority, distance, and 20% reserve battery threshold in <15ms.

Space-Time Micro-Leases

Mutual-exclusion access to narrow corridors with 4.8s TTL auto-expiry, permanently preventing deadlock.

Zero-Trust Security & ISO Safety

Ed25519 cryptographic signing prevents V2V packet spoofing. Compliant with ISO 3691-4 industrial safety envelopes.
